# CoeFont — app-specific test instructions

- Try all modes: **Solo**, **Face-to-Face**, and **Side-by-Side**. For each one, after changing
  the mode you MUST press **Start**, speak commands and let it run for a few seconds, then
  **Stop**, before moving on to the next mode.
- On **Face-to-Face** mode, try all language combinations of input / output.
- Change a setting, then go back, try out a conversation, and then go back again.
- After doing the Interpreter mode, make sure to go to the **Note-Taker** mode and then try a
  few of the languages by starting it on and off.
