# webbot — paste-to-install (self-contained, no repo needed)

This single file contains the **entire webbot web-app tester** (CLI + libs + prompt
templates + Claude skill), embedded as base64. Hand this whole file to Claude Code
and say *"run the install script in this file"* — Claude will write every file to
`~/.webbot/web/` and run the installer. No GitHub, no `curl`, no clone required.

**Prerequisites Claude can't auto-install for you:** Node.js 20+, `npx`, and the
`claude` CLI on PATH. The installer checks these and stops with a clear message if
any are missing. It *will* auto-install Chromium (via `npx playwright install`).

**What the script does**
1. Writes 14 files (~51 KB decoded) into `~/.webbot/web/`.
2. Runs `webbot install` → verifies deps, installs Chromium, symlinks `webbot` onto
   your PATH, and copies the webbot skill into `~/.claude/skills/webbot/`.
3. After it finishes, open a new terminal and run `webbot doctor`, then
   `webbot init <url-or-project>`.
